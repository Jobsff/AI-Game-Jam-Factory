# C04｜预制件集成

- 使用时机：单预制件测试通过后
- 目标输出：最小集成 patch 与清理验证

## 变量区（复制后填写）

```yaml
PROMPT_ID: C04
THEME: "{{THEME}}"
GAME_NAME: "{{GAME_NAME}}"
INPUTS: "{{GAME_MAP}}｜{{契约}}｜{{宿主 Scene}}｜{{事件表}}"
CONTEXT: "{{CONTEXT}}"
TIME_LIMIT: "{{TIME_LIMIT}}"
EVIDENCE_PATHS: "{{EVIDENCE_PATHS}}"
```

## 不可违反约束

- 集成与实现分轮。
- 一次≤3文件。
- 保持 restart 行为。
- 只依据变量区与明确证据；事实不确定处写“待核验”，并给核验动作。
- 不复制第三方代码、文案或素材。

```text

先复述边界与缺失输入，再完成任务；缺失信息不得静默猜测。

```

## 固定输出格式

输出接线图、文件列表、生命周期清理点、交互/回归命令。不得追加与本任务无关的扩展方案。
