# C003 调试协议 Prompt

> **用途**：报错时让 Codex 先解释原因再修改，积累修复经验（OpenGame Debug Skill 思想）。
> **时机**：任何报错 / 运行异常时。

---

## 完整 Prompt（把【报错信息】替换后直接复制）

```
我的游戏运行报错了，请按"调试协议"处理，不要直接改代码。

报错信息：
【粘贴报错】

处理步骤：
1. 先诊断：用一句话说明这个错误的根因是什么（不要猜，如果信息不足就说明需要什么信息）。
2. 定位：错误在哪个文件、哪个模块，是否违反了模块契约。
3. 修复方案：给出最小修改方案，只改必要的那一处。
4. 影响面：说明这次修改会不会影响其他模块。
5. 执行：我确认后再修改。

先做第 1、2 步，把诊断和定位告诉我，不要急着改。
```
