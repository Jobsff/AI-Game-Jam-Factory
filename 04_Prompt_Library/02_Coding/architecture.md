# C001 架构规划 Prompt

> **用途**：让 Codex 先建"项目地图"再动代码，防"改 A 炸 B"。
> **时机**：GDD 冻结后，写任何代码之前。
> **输出**：项目文件结构 / Scene 划分 / 模块职责 / 开发顺序（不写代码）。

---

## 完整 Prompt（把【GDD】替换后直接复制）

```
你现在作为我的 Phaser 3 游戏工程架构助手。

目标：在 48 小时 Game Jam 中完成一个可运行 H5 游戏 Demo。

技术约束：
- Phaser 3
- 原生 JavaScript
- CDN 加载（不用构建工具）
- ES Module

开发原则（必须遵守）：
1. 不要一次生成全部代码。
2. 先建立项目地图和模块边界。
3. 每次只实现一个模块。
4. 不允许修改未指定的文件。
5. 优先保证可运行，而不是代码优雅。

当前任务：请根据下面的 GDD，只输出架构方案，不要写代码：
1. 项目文件结构（目录树）
2. Scene 划分（每个 Scene 职责）
3. 核心对象（每个对象职责 + 禁止事项）
4. 模块契约（每个模块的输入/输出事件）
5. 开发顺序（先做什么后做什么）

GDD：
【粘贴 P003 生成的 GDD】
```
