# C02｜模块契约

- 使用时机：实现单模块前
- 目标输出：输入输出/事件/生命周期契约

## 变量区（复制后填写）

```yaml
PROMPT_ID: C02
THEME: "{{THEME}}"
GAME_NAME: "{{GAME_NAME}}"
INPUTS: "{{GAME_MAP}}｜{{模块名}}｜{{调用方}}｜{{现有事件}}"
CONTEXT: "{{CONTEXT}}"
TIME_LIMIT: "{{TIME_LIMIT}}"
EVIDENCE_PATHS: "{{EVIDENCE_PATHS}}"
```

## 不可违反约束

- 不写实现。
- 沿用现有命名。
- 清理责任必须唯一。
- 只依据变量区与明确证据；事实不确定处写“待核验”，并给核验动作。
- 不复制第三方代码、文案或素材。

## 可直接使用的 Prompt

```text
你负责「模块契约」。读取变量区全部字段，以 输入输出/事件/生命周期契约 为目标。
先复述边界与缺失输入，再完成任务；缺失信息不得静默猜测。
必须遵守：不写实现；沿用现有命名；清理责任必须唯一。
固定输出格式：按 MODULE_CONTRACT_TEMPLATE 字段完整输出并附验收清单。
最后追加【自检清单】，逐项使用 - [ ] / - [x]，并标出所有“待核验”。
```

## 固定输出格式

按 MODULE_CONTRACT_TEMPLATE 字段完整输出并附验收清单。不得追加与本任务无关的扩展方案。
