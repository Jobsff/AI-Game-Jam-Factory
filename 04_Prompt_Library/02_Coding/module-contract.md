# C002 模块实现 Prompt

> **用途**：让 Codex 每次只实现一个模块，防止"一次生成 1000 行"失控。
> **时机**：项目地图确定后，逐个模块开发。
> **铁律**：一次只改 ≤3 个文件，改前先说明改什么、为什么。

---

## 完整 Prompt（把【模块名】【契约】替换后直接复制）

```
现在按照已确认的项目地图，实现模块：【模块名】。

这个模块的契约是：
【粘贴 C001 里该模块的职责、输入、输出事件、禁止事项】

开发规则（必须遵守）：
1. 只修改和本模块直接相关的文件，最多 3 个文件。
2. 不要创建任何新系统（如 Manager、Service 之类的新类）。
3. 不要修改其他模块的代码，不要跨文件"顺手"改别的东西。
4. 先用一句话说明你要改哪些文件、为什么，再开始写代码。
5. 输出完整可运行代码，不要用"..."省略。

开始前先回复：你要改哪几个文件、为什么。
```
