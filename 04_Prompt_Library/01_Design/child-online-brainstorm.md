# D02｜儿童在线脑暴

- 使用时机：孩子在线且愿意表达时
- 目标输出：3 个差异明显的追问与记录表

## 变量区（复制后填写）

```yaml
PROMPT_ID: D02
THEME: "{{THEME}}"
GAME_NAME: "{{GAME_NAME}}"
INPUTS: "{{主题}}｜{{孩子原话}}｜{{年龄/表达偏好}}｜{{禁区}}"
CONTEXT: "{{CONTEXT}}"
TIME_LIMIT: "{{TIME_LIMIT}}"
EVIDENCE_PATHS: "{{EVIDENCE_PATHS}}"
```

## 不可违反约束

- AI 只扩搜索。
- 不替孩子回答。
- 不把成人/AI 内容记为儿童贡献。
- 只依据变量区与明确证据；事实不确定处写“待核验”，并给核验动作。
- 不复制第三方代码、文案或素材。

## 可直接使用的 Prompt

```text
你负责「儿童在线脑暴」。读取变量区全部字段，以 3 个差异明显的追问与记录表 为目标。
先复述边界与缺失输入，再完成任务；缺失信息不得静默猜测。
必须遵守：AI 只扩搜索；不替孩子回答；不把成人/AI 内容记为儿童贡献。
固定输出格式：先复述原话；给芊芊规则题、萱萱画面题；输出三选一问题和证据字段。
最后追加【自检清单】，逐项使用 - [ ] / - [x]，并标出所有“待核验”。
```

## 固定输出格式

先复述原话；给芊芊规则题、萱萱画面题；输出三选一问题和证据字段。不得追加与本任务无关的扩展方案。
