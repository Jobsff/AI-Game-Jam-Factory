# P003 GDD 生成 Prompt

> **用途**：方案确定后，生成冻结版 GDD（游戏设计文档），作为 Codex 的输入。
> **时机**：主题公布后 20-40 分钟，方案拍板后。
> **输出**：GDD（核心循环/场景/对象/事件/资产清单）。

---

## 完整 Prompt（把【】替换后直接复制）

```
请根据下面的方案，生成一份 48 小时 Game Jam 用 GDD（游戏设计文档），要求极简、可执行、冻结边界。

已确定的方案：
- 游戏名：【填写】
- 一句话卖点：【填写】
- 核心循环：玩家通过【动作】，帮助【目标】，最终【结果】。

请按以下结构输出 GDD，控制在 800 字以内，不要写代码，只写设计：

1. 核心循环（30 秒）：输入 → 变化 → 反馈 → 继续，四步各一句。
2. 游戏状态机：列出所有状态（如 READY / PLAYING / WIN / LOSE）及切换条件。
3. 场景（Scene）划分：每个 Scene 一句话职责。
4. 核心对象清单：每个对象一句话职责（如 Player 控制移动、Item 可收集）。
5. 事件清单：列出所有事件名（如 ITEM_GET、CREATE、WIN）。
6. 美术资产清单：需要几张图，每张什么内容（越少越好，目标 ≤10 张）。
7. 音效清单：需要哪些音效（点击/胜利/失败/BGM）。
8. 明确"不做"清单：列出 48h 内坚决不做的东西（如商店、多关卡、存档）。

这份 GDD 是冻结的，后续 Codex 严格按它开发，不要扩展范围。
```
