# D06｜GDD/TDD 冻结

- 使用时机：唯一方案拍板后
- 目标输出：一页 GDD、一页 TDD、冻结项

## 变量区（复制后填写）

```yaml
PROMPT_ID: D06
THEME: "{{THEME}}"
GAME_NAME: "{{GAME_NAME}}"
INPUTS: "{{方案}}｜{{模板}}｜{{赛事限制}}｜{{8 小时保底}}"
CONTEXT: "{{CONTEXT}}"
TIME_LIMIT: "{{TIME_LIMIT}}"
EVIDENCE_PATHS: "{{EVIDENCE_PATHS}}"
```

## 不可违反约束

- 人类锁死循环/输入/状态/事件。
- 不新增玩法。
- 技术事实不明标待核验。
- 只依据变量区与明确证据；事实不确定处写“待核验”，并给核验动作。
- 不复制第三方代码、文案或素材。

## 可直接使用的 Prompt

```text
你负责「GDD/TDD 冻结」。读取变量区全部字段，以 一页 GDD、一页 TDD、冻结项 为目标。
先复述边界与缺失输入，再完成任务；缺失信息不得静默猜测。
必须遵守：人类锁死循环/输入/状态/事件；不新增玩法；技术事实不明标待核验。
固定输出格式：GDD:体验/循环/胜负/范围；TDD:状态/事件/模块/测试；冻结签字表。
最后追加【自检清单】，逐项使用 - [ ] / - [x]，并标出所有“待核验”。
```

## 固定输出格式

GDD:体验/循环/胜负/范围；TDD:状态/事件/模块/测试；冻结签字表。不得追加与本任务无关的扩展方案。
