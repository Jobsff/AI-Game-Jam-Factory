# P001 主题拆解 Prompt

> **用途**：现场主题公布后，第一步把主题拆成"可答题角度"。
> **时机**：主题公布后 0-5 分钟。
> **输入**：现场公布的主题词/一句话。
> **输出**：三层拆解（字面/隐喻/游戏）+ 玩法方向建议。

---

## 完整 Prompt（把【】替换后直接复制）

```
我们正在参加一个 48 小时 AI Game Jam，现场公布的主题是：【填写主题】。

请先不要想具体游戏，帮我把这个主题拆解成"可答题空间"，按三层来拆：

第一层【字面层 What】：这个主题字面上直接表达什么？列出所有直接含义。

第二层【隐喻层 Why】：这个主题背后的情绪是什么？用「方向 → 情绪」的形式列出至少 4 组（例如"失败重来 → 希望"、"旧物恢复 → 温暖"）。

第三层【游戏层 How】：这个主题可以转化成什么游戏机制？重点不是"做一个关于它的故事"，而是"它能不能变成一个可玩的机制"（例如"重生 → 每次失败获得新能力"、"重生 → 修复被破坏的世界"）。

最后请给我：
1. 一张「主题机会地图」（故事方向 / 情绪方向 / 玩法方向 / 视觉方向 各列 3-5 个）；
2. 3 个最值得做的玩法方向，每个用一句话"玩家通过____，帮助____，最终____"描述；
3. 一个最不推荐的方向（容易做俗的那个），并说明为什么。
```
