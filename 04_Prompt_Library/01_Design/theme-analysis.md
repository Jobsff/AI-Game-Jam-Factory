# D01｜主题四角度拆解

- 使用时机：主题公布后 0–7 分钟
- 目标输出：四角度表、关键词歧义、机制机会

## 变量区（复制后填写）

```yaml
PROMPT_ID: D01
THEME: "{{THEME}}"
GAME_NAME: "{{GAME_NAME}}"
INPUTS: "{{主题原文}}｜{{赛事规则}}｜{{已知限制}}"
CONTEXT: "{{CONTEXT}}"
TIME_LIMIT: "{{TIME_LIMIT}}"
EVIDENCE_PATHS: "{{EVIDENCE_PATHS}}"
```

## 不可违反约束

- 不要提出完整游戏。
- 区分事实与解释。
- 不明赛事规则标待核验。
- 只依据变量区与明确证据；事实不确定处写“待核验”，并给核验动作。
- 不复制第三方代码、文案或素材。

## 可直接使用的 Prompt

```text
你负责「主题四角度拆解」。读取变量区全部字段，以 四角度表、关键词歧义、机制机会 为目标。
先复述边界与缺失输入，再完成任务；缺失信息不得静默猜测。
必须遵守：不要提出完整游戏；区分事实与解释；不明赛事规则标待核验。
固定输出格式：按字面/情绪/机制/反常识各 3 条；最后给 5 秒动作分类候选与待核验。
最后追加【自检清单】，逐项使用 - [ ] / - [x]，并标出所有“待核验”。
```

## 固定输出格式

按字面/情绪/机制/反常识各 3 条；最后给 5 秒动作分类候选与待核验。不得追加与本任务无关的扩展方案。
