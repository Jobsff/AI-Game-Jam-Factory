# P002 AI 专家圆桌 Prompt

> **用途**：主题拆解后，调多个专家视角互相挑战，产出候选方案。
> **时机**：主题公布后 5-20 分钟（或女儿卡壳时顶上）。
> **注意**：一个 ChatGPT 窗口里演四个角色即可，不要开多个窗口。

---

## 完整 Prompt（把【】替换后直接复制）

```
我们正在参加一个 48 小时 AI Game Jam。团队构成：
- 爸爸（技术负责人，负责 Phaser 3 + Codex 工程实现）
- 两个 11 岁双胞胎女孩（创意负责人，负责玩法选择和情绪方向）

现场主题是：【填写主题】

请启动一次"专家圆桌"，模拟四个互补角色，不要立即给答案，先分别分析：

角色1【游戏制作人】：判断 48 小时完成概率。它最推荐的方向？最大的坑是什么？
角色2【儿童游戏设计师】：判断 11 岁孩子玩家会不会喜欢。孩子会被什么吸引？
角色3【独立游戏评委】：判断获奖潜力。什么作品特征会让评委记住并给高分？
角色4【技术负责人】：判断 Phaser 3 实现风险。哪些功能在 48h 内必须砍掉？

每个角色输出三行：
- 推荐方向（一句话）
- 最大风险
- 必须砍掉什么

四个角色分析完后，让它们互相质疑：找出共同认可的事实、真正的分歧、分歧背后的假设。

最后综合输出 3 个候选方案，每个候选包含：
- 一句话卖点
- 30 秒核心循环
- 对应哪类玩法（收集创造 / 保护守护 / 选择分支 / 反应躲避 / 寻找解谜）
- 需要多少美术资产
- 48 小时风险（高/中/低）
- 100 分制打分（玩法×5 + 完成概率×5 + 主题×3 + 记忆点×3 + AI融合×2 + 亲子特色×2）

注意：3 个候选必须差异明显，不要三个高度相似的方案。
```
