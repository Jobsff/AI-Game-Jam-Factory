# D03｜儿童卡壳再介入

- 使用时机：沉默 10 秒或连续说不知道
- 目标输出：低压力二选一/动作/画图入口

## 变量区（复制后填写）

```yaml
PROMPT_ID: D03
THEME: "{{THEME}}"
GAME_NAME: "{{GAME_NAME}}"
INPUTS: "{{主题}}｜{{已问问题}}｜{{孩子最后反应}}｜{{可选表达方式}}"
CONTEXT: "{{CONTEXT}}"
TIME_LIMIT: "{{TIME_LIMIT}}"
EVIDENCE_PATHS: "{{EVIDENCE_PATHS}}"
```

## 不可违反约束

- 不连续逼问。
- 不评价答案。
- 不诱导既定成人方案。
- 只依据变量区与明确证据；事实不确定处写“待核验”，并给核验动作。
- 不复制第三方代码、文案或素材。

## 可直接使用的 Prompt

```text
你负责「儿童卡壳再介入」。读取变量区全部字段，以 低压力二选一/动作/画图入口 为目标。
先复述边界与缺失输入，再完成任务；缺失信息不得静默猜测。
必须遵守：不连续逼问；不评价答案；不诱导既定成人方案。
固定输出格式：给 3 条可直接念的短句、等待时间、接受的非语言回答、停止条件。
最后追加【自检清单】，逐项使用 - [ ] / - [x]，并标出所有“待核验”。
```

## 固定输出格式

给 3 条可直接念的短句、等待时间、接受的非语言回答、停止条件。不得追加与本任务无关的扩展方案。
