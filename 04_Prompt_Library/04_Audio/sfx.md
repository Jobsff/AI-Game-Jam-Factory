# S002 音效包（SFX Pack）Prompt

> **用途**：批量生成游戏音效。
> **时机**：玩法跑通后（Day2 体验打磨阶段）。
> **标准包**：click（点击）/ win（胜利）/ fail（失败）/ magic（特效）。

---

## 完整 Prompt（把【】替换后用于 ElevenLabs）

```
请生成一组游戏音效，风格统一【如"卡通轻快"】：
1. click：短促清脆的点击声（0.3 秒）
2. win：上扬的胜利音（1.5 秒）
3. fail：下坠的失败音（1 秒）
4. magic：梦幻的魔法特效声（1 秒）
每个音效短小、独立、无背景杂音。
```

## 要点

- 音效文件名统一：`sfx_click.mp3`、`sfx_win.mp3`、`sfx_fail.mp3`、`sfx_magic.mp3`
- 只做 4 个核心音效就够，不要贪多
- 优先保证"点击反馈"（这是手感的基础）
