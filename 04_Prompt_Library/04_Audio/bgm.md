# S001 背景音乐（BGM）Prompt

> **用途**：生成游戏背景音乐（ElevenLabs Music API）。
> **时机**：Demo 完成后（第二晚），不在第一天做。
> **输入**：情绪 + 节奏 + 时长。

---

## 完整 Prompt（把【】替换后用于 ElevenLabs）

```
情绪：【如"温暖治愈 / 紧张冒险 / 梦幻神秘"】
节奏：【如"舒缓 80 BPM / 轻快 120 BPM"】
乐器：【如"钢琴 + 木吉他 / 电子合成器"】
时长：60 秒，循环无缝
用途：手机 H5 小游戏背景音乐
风格参考：【如"动物森友会式的轻松感"】
```

## 要点

- 音效优先级：点击反馈 > 胜利反馈 > 情绪音乐
- BGM 只在功能跑通后再加，别让音乐拖慢第一晚进度
- 记得做"无缝循环"版本
