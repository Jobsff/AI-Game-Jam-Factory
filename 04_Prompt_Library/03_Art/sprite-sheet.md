# A003 批量素材 / Sprite Sheet Prompt

> **用途**：批量生成游戏素材（图标/道具/UI 元素）。
> **时机**：核心素材确定后。
> **关键技巧**：用品红背景(#FF00FF)网格生图，配合 game-sprite-forge 技能批量抠图。

---

## 完整 Prompt（把【】替换后拼上风格前缀）

```
【风格前缀】 + 一组【素材类型，如"游戏道具图标"]，共【数量，如"6"]个，包括：【具体清单，如"星星、钥匙、药水、金币、宝石、心形"]，每个都画在品红色背景(#FF00FF)上，等距排列，游戏素材，无文字，无水印
```

## 品红网格抠图工作流

1. 用 #FF00FF 纯品红背景批量生图（便于脚本自动识别边界）
2. 用 `game-sprite-forge` 技能里的 Python 脚本批量抠图，输出透明 PNG 逐帧
3. 成品命名规范：`item_star.png`、`item_key.png`（统一前缀，方便代码引用）

## 备选（接口不稳定时）

- 接口挂了 → 切几何风（Canvas/Phaser Shape 直接画）
- 生图慢 → 只生成主角 + 最大视觉物，其余用程序改色/缩放复用
