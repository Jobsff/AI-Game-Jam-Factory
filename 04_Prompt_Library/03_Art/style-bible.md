# A01｜Style Bible

- 使用时机：首批生图前
- 目标输出：视觉规则与禁用清单

## 变量区（复制后填写）

```yaml
PROMPT_ID: A01
THEME: "{{THEME}}"
GAME_NAME: "{{GAME_NAME}}"
INPUTS: "{{主题}}｜{{情绪}}｜{{目标设备}}｜{{程序美术能力}}"
CONTEXT: "{{CONTEXT}}"
TIME_LIMIT: "{{TIME_LIMIT}}"
EVIDENCE_PATHS: "{{EVIDENCE_PATHS}}"
```

## 不可违反约束

- 非模仿型。
- 不引用在世艺术家/特定作品风格。
- 可程序降级。
- 只依据变量区与明确证据；事实不确定处写“待核验”，并给核验动作。
- 不复制第三方代码、文案或素材。

## 可直接使用的 Prompt

```text
你负责「Style Bible」。读取变量区全部字段，以 视觉规则与禁用清单 为目标。
先复述边界与缺失输入，再完成任务；缺失信息不得静默猜测。
必须遵守：非模仿型；不引用在世艺术家/特定作品风格；可程序降级。
固定输出格式：输出形状/色板/材质/线条/光照/UI/动效/禁止项及 5 张验收描述。
最后追加【自检清单】，逐项使用 - [ ] / - [x]，并标出所有“待核验”。
```

## 固定输出格式

输出形状/色板/材质/线条/光照/UI/动效/禁止项及 5 张验收描述。不得追加与本任务无关的扩展方案。
