# A001 画风统一 Prompt（Style Bible）

> **用途**：先定一套画风，后面所有图都套同一段"风格描述"，避免美术变缝合怪。
> **时机**：方案确定后，生成第一张图之前。
> **关键**：把下面这段"风格前缀"固定下来，所有生图都带上。

---

## 第一步：让 GPT 定画风（把【主题】替换）

```
我要为一个 48h 游戏比赛做美术，主题是【主题】。请帮我定一套统一画风，输出"风格圣经"，包含：
1. 画风一句话描述（如"明亮治愈的扁平卡通风"）
2. 主色板（给出 4-5 个主色 + 各配一个 hex 色值）
3. 材质/笔触（如"无描边、柔和渐变、圆润造型"）
4. 光照氛围（如"暖阳、通透、梦幻"）
5. 角色/场景/UI 各自的风格关键词
输出要能直接复制，作为后面所有生图的"风格前缀"。
```

## 第二步：固定"风格前缀"

把第一步输出的画风描述，存成一个固定前缀，之后所有生图 Prompt 都拼在开头，例如：

```
【风格前缀】 + 一个可爱的小狐狸角色，正面，全身，游戏素材，纯色背景
```

> 目标：风格统一 > 素材数量。1 个高级角色 > 20 个风格漂移的素材。
