# A002 角色生成 Prompt

> **用途**：生成主角 / 核心角色。
> **时机**：画风确定后。
> **输入**：角色设定 + 情绪 + 姿势。

---

## 完整 Prompt（把【】替换后，前面拼上 A001 的风格前缀）

```
【风格前缀】 + 一个【角色描述，如"圆滚滚的小机器人"]，【情绪/性格，如"害羞但善良"]，【姿势，如"正面站立、张开双手"]，游戏角色素材，全身，居中，纯色背景，无文字，无水印
```

## 角色生成要点

- 一次只生成一个角色，保持主体突出
- 生成后记得用抠图工具（rembg 等）去背景，保留透明 PNG
- 同一角色要多个表情时，固定前面描述，只改情绪词，保证一致性
