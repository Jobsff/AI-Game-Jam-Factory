# 获奖案例分析（第一手资料）

> 来源：联网查证（2026-08-25）。重点研究"独立开发者 / 亲子组合"如何获奖。

## 案例 1：Snip It（Hugging Face 首届 Open Source AI Game Jam 冠军）

- **赛事**：48h，主题 "Expanding"，1300+ 报名 / 88 作品
- **玩法**：博物馆画作活过来，剪裁画中物品揭开隐藏秘密
- **AI 用法**：Stable Diffusion 生成素材
- **评分标准**：趣味性 / 创意 / 主题契合（三标准）
- **启示**：冠军不是技术最强，而是**概念最清楚**——"剪掉画的一部分让隐藏故事出现"，一句话能懂、30 秒能玩。

## 案例 2：《俺大周不中嘞》（知乎游戏 Game Jam，新人团队独中三元）

- **团队**：新人团队"进京赶考"
- **奖项**：最佳新人奖 + 最佳 AI 应用奖 + 最佳作品奖
- **玩法**：以周幽王身份发布政令，复兴周朝
- **启示**：**美术出色 + 剧情丰满 + 完成度极高**，48h 只睡 8 小时硬拼完成度。

## 案例 3：Little Parrot + 妈妈（亲子组合获奖先例 ⭐）

- **团队**：济南高二独立开发者 + 妈妈当策划
- **作品**：《War Horizon Finals》3D 恐怖逃生游戏
- **结果**：入选最佳作品
- **启示**：**"亲子组合"本身就是故事**，能获奖。但关键是要升级成"AI 时代儿童创作者实验"，而不是"亲子活动"。

## 三条共性规律

1. **概念清楚 > 技术强**：获奖作品都能一句话讲清、30 秒理解
2. **小团队靠身份差异**：亲子组合 = 天然记忆点
3. **高完成度 > 内容量**：10 分钟打磨 > 10 小时内容堆砌

## 对我们（父女战队）的迁移

| 案例启发 | 我们的动作 |
|----------|-----------|
| 概念一句话讲清 | 决策器 + 拍板三问强制收敛 |
| 亲子身份是加分 | 答辩话术 + 视频保留女儿参与片段 |
| 完成度 > 内容量 | 5 模板 + 四个硬节点红线 + 砍功能纪律 |
| AI 是特色不是工具 | 展示"女儿描述→AI生成→运行"链路 |

## 三个易犯盲区（对照自省）

1. 太相信 AI 生产能力 → 瓶颈是"选择"不是"生成"，80% 胜负来自选题
2. 低估孩子价值 → 要的是"怪物其实害怕孤独"这种非专业差异，不是完整方案
3. 过度追求工程先进性 → 评委不会因 Agent 架构漂亮给分
