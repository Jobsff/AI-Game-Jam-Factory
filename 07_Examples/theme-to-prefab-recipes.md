# 主题 → 玩法母件 → Prefab 组合：5 个配方

> 这些是结构示例，不是预设参赛方案。现场必须重新通过四角度、儿童价值判断和六指标评分。

## 1. “最后一束光” → 收集创造

- [ ] 一句话：玩家收集不同颜色的微光，两两组合，让黑暗地图出现新的可行路径。
- [ ] 母件：`template_collect_create`。
- [ ] Prefab：`Clickable` + `Merge` + `ScoreSystem` + `Popup`。
- [ ] 最小循环：点光点 → 选择两个 → 合成 → 解锁结果 → 三次完成。
- [ ] 8 小时保底：3 种光、3 个固定结果、程序几何美术。

## 2. “守护看不见的朋友” → 核心防守

- [ ] 一句话：玩家从声音提示判断威胁方向，点击驱散噪点来保护中央呼吸光。
- [ ] 母件：`template_defense`。
- [ ] Prefab：`Spawner` + `Clickable` + `HealthSystem` + `CountdownTimer`。
- [ ] 最小循环：威胁出现 → 点击处理 → 核心扣血/恢复 → 守到计时结束。
- [ ] 8 小时保底：单一敌人、20 秒、圆形与波纹反馈。

## 3. “每次告别都留下东西” → 抉择叙事

- [ ] 一句话：每轮只能带走一个物件，留下的物件会改变下一轮的世界反馈。
- [ ] 母件：`template_choice`。
- [ ] Prefab：`UIButton` + `DialogBox` + `StateMachine` + `Popup`。
- [ ] 最小循环：读局面 → 二选一 → 世界变化 → 三轮结局。
- [ ] 8 小时保底：3 轮、2 按钮、3 个文字结局，无分支地图。

## 4. “时间只在你停下时前进” → 反应操作

- [ ] 一句话：玩家移动时障碍冻结，停下时出口生长但危险也逼近。
- [ ] 母件：`template_action`。
- [ ] Prefab：`Draggable` + `Spawner` + `CountdownTimer` + `HealthSystem`。
- [ ] 最小循环：拖动避让 → 松手积累出口 → 危险推进 → 逃出/失败。
- [ ] 8 小时保底：一个玩家、一个危险源、单条进度条。

## 5. “博物馆里缺失的颜色” → 隐藏寻找

- [ ] 一句话：玩家在画面中找出不属于当前色板的细节，每次发现恢复一段故事颜色。
- [ ] 母件：`template_find`。
- [ ] Prefab：`Clickable` + `CountdownTimer` + `ScoreSystem` + `DialogBox`。
- [ ] 最小循环：观察 → 点击异色线索 → 反馈故事片段 → 找齐/超时。
- [ ] 8 小时保底：5 个目标、单场景、程序色块，不使用第三方馆藏素材。
