# 开源与第三方政策

## 比赛现场规则

- [ ] 官方模板只用于研究接口与行为，自行重写实现；不复制第三方代码或素材。
- [ ] 新依赖先记录名称、版本、来源、license、用途与分发文件。
- [ ] 依赖优先级：MIT / BSD-2-Clause / BSD-3-Clause / Apache-2.0；Apache 同时检查 NOTICE/专利条款。
- [ ] GPL / AGPL 可能触发衍生作品或网络交互义务，未经逐项审计不引入。
- [ ] CC-NC 限制商业使用；不进入拟商业化版本。CC BY/SA 等也须核对署名与相同方式共享义务。
- [ ] 不明 license、仅“免费”、来源不明素材一律标“待核验”并排除提交包。

## 商业化前门槛

- [ ] 按文件逐项审计代码、字体、图片、音频、模型、生成工具条款与数据来源。
- [ ] 核对许可证文本、NOTICE、署名位置、source offer、商标与专利要求。
- [ ] 替换所有“不明／待核验／仅限非商业”资产。
- [ ] 生成最终 SBOM/third-party notices 并由具备相应资质的人员复核。

仓库边界见 [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md)。本政策不是对具体作品许可证兼容性的结论。
