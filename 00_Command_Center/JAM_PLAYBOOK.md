# 🎮 JAM_PLAYBOOK 作战手册

> 一句话战略：48h 不是做"优秀小游戏"，而是做**30 秒打动评委、3 分钟讲清故事、48h 稳定运行的「AI 亲子共创原型」**。

## 制胜公式

```
最终选题分 = 获奖潜力 × 0.5 + 48h成功概率 × 0.3 + 父女团队特色 × 0.2
```

## 三个角色定位（防"假参与"）

| 角色 | 谁 | 职责 |
|------|-----|------|
| 创意总监 | 女儿（芊芊+萱萱）| 价值判断 + 最终选择（不是生产者）|
| 制作负责人 | 斐哥 | 架构 + Codex 执行 |
| 顾问团 | AI | 扩大搜索空间、验证方案 |

**关键认知**：11 岁孩子的价值不是"想得多"，而是"我看到会不会马上想玩"这种非专业判断。

## 现场 5 步流水线

```
主题公布
  → ① 决策器分类（decision.html，60 秒）
  → ② 孩子脑暴（P001 主题拆解）
  → ③ AI 专家圆桌（P002，产出 3 候选）
  → ④ 孩子投票拍板（低门槛 3 问）
  → ⑤ 复制模板 → Codex 开发（C001→C002→C003）
```

## 技术铁律（OpenGame 借魂不搬家）

1. **模板库**：5 个玩法模板，现场不 from zero
2. **模块契约**：Codex 一次只改 ≤3 个文件，改前说明
3. **Debug 协议**：报错先诊断再改，不盲目堆代码

## 评分 ROI（8 维度资源投向）

- **S 级重点堆**：玩法(35%)、完成度(25%)、创意(15%)
- **A 级**：AI 使用深度(10%)、路演表达
- **B 级及格即可**：美术(10%)、音效
- **C 级放弃**：商店/装备/多关卡/成长系统

## 最大风险与退出条件

- **最大风险**：想同时满足"孩子参与+高质量+商业化+复杂玩法"→ 四不像
- **退出条件**：前 8h 若核心玩法没跑通 / AI 生图不稳定 / 女儿创意转不成机制，立即砍到只留一个玩法
