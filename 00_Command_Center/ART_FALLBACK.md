# 美术三级降级

| 级别 | 做法 | 现场定义 |
|---|---|---|
| A 完整 AI 视觉 | 统一 Style Bible 后生成角色、背景、UI、关键反馈 | 资产稳定、风格一致、导入时间可控 |
| B 关键资产 + 程序绘制 | 只保留主角/关键记忆画面，背景、粒子、按钮用 Phaser Graphics | 单项生成失败或风格修正拖慢集成 |
| C 几何风 | 圆/方/三角、纯色、文字与 tween；玩法反馈优先 | 无 AI 接口、资产不可用或交付风险高 |

## 90 分钟降级计时器

- [ ] 第 0 分钟：记录当前等级、最小资产清单和验收图。
- [ ] 第 30 分钟：关键资产没有 1 张可导入版本，停止扩 prompt。
- [ ] 第 60 分钟：仍需大面积返工，准备下一级替代清单。
- [ ] 第 90 分钟：关键资产仍不能进游戏，立即降一级；不因“快好了”续时。
- [ ] 每降一级更新 Sprite Manifest、AI usage log 与 GAME_MAP。
