# 60 分钟选题拍板 SOP

入口：[`decision.html`](../03_AI_Decision_System/decision.html)｜圆桌：[`AI_ROUNDTABLE_SOP.md`](AI_ROUNDTABLE_SOP.md)

| 时间 | 现场动作 | 强制产出 |
|---|---|---|
| 00–02 | 原样记录主题，不解释。 | 主题原文 |
| 02–07 | 从字面、情绪、机制、反常识各说一句。 | 四角度 |
| 07–12 | 芊芊说玩家动作，萱萱说记忆画面。 | 儿童原始点子 |
| 12–15 | 5 秒分类：创造、保护、选择、操作、发现。 | 最多 2 个玩法母类 |
| 15–20 | 只写 3 个候选：一句话玩法、30 秒记忆点、8 小时保底。 | 三候选，禁止第 4 个 |
| 20–35 | 执行一次 15 分钟专家圆桌。 | 共识、分歧、最小验证 |
| 35–42 | 做纸面或点击级最小验证，不写正式代码。 | 可证伪结果 |
| 42–50 | 六指标评分并执行硬淘汰。 | 自动排序 |
| 50–55 | 孩子回答：最想玩、最想看、最不像别人。 | 真实价值判断 |
| 55–58 | 只剩 8 小时还能否完整交付？ | 最终范围 |
| 58–60 | 制作人选择唯一方案并锁定。 | 决策导出、下一步 |

## 离场条件

- [ ] 唯一方案未触发硬淘汰。
- [ ] 孩子原话、AI 建议和制作人决定已分开记录。
- [ ] 已确定 `JAM_DEMO`、8 小时保底和第一个可玩里程碑。
- [ ] 60 分钟到点必须结束讨论；未拍板则选最高分未淘汰项。
