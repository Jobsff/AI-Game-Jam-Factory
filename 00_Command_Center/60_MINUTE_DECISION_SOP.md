# 60 分钟选题拍板 SOP

入口：[`decision.html`](../03_AI_Decision_System/decision.html)｜圆桌：[`AI_ROUNDTABLE_SOP.md`](AI_ROUNDTABLE_SOP.md)｜规则：[`DECISION_RULES.md`](DECISION_RULES.md)

## 0–60 分钟逐分钟执行

| 时间 | 主持人可直接念的话 | 产出／截止规则 |
|---|---|---|
| 00:00–02:00 | “原样抄下主题。两分钟内不解释、不提游戏。” | 主题原文进入决策器；来源不清标“待核验”。 |
| 02:00–07:00 | “每人从字面、情绪、机制、反常识各说一句；不评价。” | 四角度字段各至少 1 句；07:00 强停。 |
| 07:00–12:00 | “芊芊先说最想做的动作，萱萱再说最想看到的画面。” | 孩子在线用 [`CHILD_CREATIVE_SCRIPT.md`](CHILD_CREATIVE_SCRIPT.md)；卡壳则切换同文档脚本。 |
| 12:00–15:00 | “玩家主要在创造、保护、选择、操作还是发现？五秒选一类。” | 选 5 秒动作分类；最多保留 2 类。 |
| 15:00–20:00 | “只写三个候选：一句话玩法、30 秒记忆点、8 小时保底。” | 恰好 3 个候选；禁止第 4 个。 |
| 20:00–22:00 | “现在把决策器上下文复制到主 ChatGPT 窗口。” | 复制圆桌上下文；Codex 窗口此时不写代码。 |
| 22:00–45:00 | “四位专家必须指出彼此遗漏的致命问题，并给最小验证。” | 执行 30 分钟圆桌的压缩段；45:00 后禁止新增候选。 |
| 45:00–50:00 | “逐项 1–5 分，先独立打分再公开。” | 六指标加权；填写核心美术数；硬淘汰自动执行。 |
| 50:00–55:00 | “孩子只回答：最想玩、最想看、最不像别人的是哪个？” | 记录价值判断原话，不把 AI 建议记成孩子贡献。 |
| 55:00–58:00 | “如果只剩 8 小时，哪个仍能完整开始、胜负、重来？” | 自动排序；并列按完成概率→玩法清晰→记忆点。 |
| 58:00–60:00 | “制作负责人现在选唯一方案，说出理由并锁定。” | 填拍板理由、锁定唯一方案、导出 Markdown/JSON。60:00 未锁定则拍最高分未淘汰项。 |

## 离场清单

- [ ] 已导出决策 Markdown 与 JSON。
- [ ] 唯一方案未触发任何硬淘汰。
- [ ] 孩子原话与 AI 建议分别记录。
- [ ] 已创建 GDD/TDD/GAME_MAP，进入技术冻结。
